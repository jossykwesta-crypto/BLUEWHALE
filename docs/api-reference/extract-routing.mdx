# extract_routing

Extracts routing information from a memo string.

## Request

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `memo` | `string \| null` | No | Memo string to parse for routing information. |

### Memo value semantics

The `memo` field distinguishes between three cases:

| Value | Meaning | Result |
| --- | --- | --- |
| `memo: ""` | Empty string — treated as no memo. | Normalized cleanly; `routingId` is `null` with no warnings. |
| `memo: null` | Explicitly no memo. | `routingId` is `null`. |
| `memo` omitted | Field not provided. | `routingId` is `null`. |

An empty string `""` is never treated as a validation error; it is normalized to the same result as `null` or an omitted `memo`.

## Response

| Field | Type | Description |
| --- | --- | --- |
| `routingId` | `string \| null` | Extracted routing identifier, or `null` when no memo is present. |

## Examples

### Empty memo

```json
{
  "memo": ""
}
```

```json
{
  "routingId": null
}
```

### Null memo

```json
{
  "memo": null
}
```

```json
{
  "routingId": null
}
```

### Omitted memo

```json
{}
```

```json
{
  "routingId": null
}
```
